# Scheme Sahayak AI - Stability Fixes

This build fixes the frontend freeze caused by the previous LanguageContext MutationObserver
observing characterData mutations generated by its own translator.

Changes:
- Safe multilingual DOM bridge: observes React child-list changes only and disconnects while translating.
- Added State + Field/Purpose filters to Explore Schemes.
- Added verified-partner nearby API with Haversine distance calculation.
- Added Leaflet map with user location + partner pins.
- Added multilingual labels for filters and location states.
- Enabled React Router v7 future flags to remove migration warnings.
- Python files compile successfully.

Run from the folder containing requirements.txt:
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt
  .\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload

In another terminal:
  .\.venv\Scripts\python.exe -m uvicorn ai.main:app --host 127.0.0.1 --port 8001 --reload

Frontend:
  cd frontend
  npm.cmd install
  npm.cmd run dev

Note: Nearby partner results are only returned when verified partner records exist in
data/scheme_sahayak.db. No fake partner locations are seeded.
